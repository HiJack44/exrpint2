Exprint2 is the second version of label formating software dveloped for Muziker company to format labels with customer orders and reservations that are supposed to be printed on a Zebra label printer.
The program can paste spreadsheet data and format them according to pre-determined template. It should ensure correct formating, so the printer will use the labels to it's fullest instead of ruining them.
The output of the program is text file named print_list.txt that should be redy to print on the Zebra printer.

There are two log files in the support folder. Log.txt is logging the main app and updater_log.txt is logging the updater.exe during updates.

Installation:
The program comes in .zip file with ready-to-use exe files of the app and the updater, config file and help images. Just unpack and run exprint2.exe.

Known errors:
With larger table (20+ rows) there is an issue of customtkinter returning cycling error.
